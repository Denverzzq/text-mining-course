# 《巫师3：狂猎》剧情文本解包与分析说明

本项目为课程大作业——**《巫师3》与《猎魔人》** 的文本数据支持与解包模块。
本目录包含从《巫师3：狂猎》游戏资源中提取、清洗并结构化整理的剧情全量文本，以及配套的自主开发解包程序 `extract_w3strings.py`。

## 🛠️ 文本处理与优化细节

1. **场景对话连续性（按 String ID 排序）**
   * 《巫师3》RedEngine 引擎将同一任务、同一场景和交互对话树中的文本连续存放在相邻的 ID 区段中。
   * 本程序输出时按 ID 顺序排序，最大程度保留了对话树的上下文承接关系与剧情戏剧张力。

2. **版面排版清洗与标签去除**
   * 原生数据中的 `<br>`、`<br><br>` 等换行标签已转换为符合现代阅读习惯的自然段落。
   * 彻底剔除了游戏内部格式化标签（如 `<i>`、`<b>`、`<font color="...">` 等），消除排版乱码。

3. **剧情与系统元素细粒度剥离**
   * 采用模式识别规则，将手稿配方、控制台按键提示（如 `[BUTTON_]`、`<<GUI_>>`）、画质设置、存档弹窗与数值属性分离至全量表中，保证剧情阅读文件的纯净度。

## 💻 解包程序（extract_w3strings.py）使用方法

本目录下附带的 `extract_w3strings.py` 是针对《巫师3》本地化字符串容器（`.w3strings`）自主实现的解析、去混淆与文本分类工具。

### 1. 环境依赖
* **Python 3.6 或更高版本**（推荐 Python 3.8+）
* **无需安装任何第三方库**：程序全部基于 Python 标准库（`struct`、`re`、`os`、`argparse`）编写，开箱即用。

### 2. 兼容性说明
* **游戏版本支持**：
  * 支持《巫师3》**次世代重制版 / Next-Gen（v164 格式，UTF-8 编码）**；
  * 兼容《巫师3》**原版 / 年度版（v162 / v163 格式，UTF-16LE 编码）**。
* **语言包支持**：
  * 内置 CD Projekt Red 官方语言密钥哈希表，支持简体中文（`cn`）、繁体中文（`zh`）、英语（`en`）、日语（`jp`）、德语（`de`）、法语（`fr`）、波兰语（`pl`）、俄语（`ru`）等各语种原生文件及社区 MOD 文件。

### 3. 命令行调用方式

打开终端或 PowerShell，进入本脚本所在目录执行：

#### 基础用法（默认读取当前目录下的 `zh.w3strings` 并输出至 `extracted_texts/`）：
```bash
python extract_w3strings.py
```

#### 指定输入文件（如解包简体中文语言包 `cn.w3strings`）：
```bash
python extract_w3strings.py cn.w3strings
```

#### 指定输出目录：
```bash
python extract_w3strings.py cn.w3strings -o ./extracted_texts_cn
```

#### 查看帮助说明：
```bash
python extract_w3strings.py --help
```
